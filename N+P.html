窒素とリン（15族）のまとめ

彩色 = 考试重点，会出题 灰色 = 了解即可，不出题
💨
窒素の単体 氮气
  • 15族の非金属元素（N、P）は価電子を5個もつ。
  • 窒素はタンパク質や核酸の重要な構成元素である。
  • 窒素 N2 は無色・無臭の気体で、空気中に体積比で約78％存在する。
  • 工業的には液体空気の分留で得られる。
  • 液体窒素は冷却剤として使われる。
  • 一般に反応性が乏しく安定である。
  • 融点 −210℃、沸点 −196℃、密度 1.25 g/L。
🧪
アンモニア NH3
  • 刺激臭のある無色の有毒な気体（融点 −78℃、沸点 −33℃）。
  • 窒素を含む多くの化合物の原料となる。
  • 工業的製法：ハーバー・ボッシュ法（鉄を含む触媒の存在下）。
  • 実験室：塩化アンモニウム NH4Cl などのアンモニウム塩を強塩基とともに加熱して発生、上方置換で捕集。
  • 水によく溶け、水溶液（アンモニア水）は弱塩基性を示す。
  • アンモニアと塩化水素が大気中で反応して白煙（NH4Cl）を生じる。
  • 用途：硝酸の原料、尿素 CO(NH2)2 など肥料の原料。
  • 尿素の合成：CO2 + 2NH3 →(180℃) CO(NH2)2 + H2O
N2 + 3H2 →(触媒) 2NH3
2NH4Cl + Ca(OH)2 →(加熱) CaCl2 + 2H2O + 2NH3
NH3 + H2O ⇌ NH4+ + OH−
NH3 + HCl → NH4Cl
🌫️
一酸化窒素 NO 一氧化氮
  • 無色の気体で、水に溶けにくい（沸点 −152℃）。
  • 実験室：銅 Cu に希硝酸を加えて発生させ、水上置換で捕集。
  • 空気中ですみやかに酸化され、赤褐色の二酸化窒素 NO2 になる。
3Cu + 8HNO3 → 3Cu(NO3)2 + 4H2O + 2NO
2NO + O2 → 2NO2
🟤
二酸化窒素 NO2 二氧化氮
  • 刺激臭のある赤褐色の有毒な気体。
  • 実験室：銅に濃硝酸を加えて発生させ、下方置換で捕集。
  • 常温では一部が無色の四酸化二窒素 N2O4 に変化する。
  • 水に溶けると硝酸を生じる。
Cu + 4HNO3 → Cu(NO3)2 + 2H2O + 2NO2
2NO2 ⇌ N2O4
3NO2 + H2O → 2HNO3 + NO

⚗️
硝酸 HNO3 の製法 オストワルト法
  • 硝酸 HNO3 は水に溶けやすく揮発性のある無色の液体（融点 −42℃、沸点 83℃）。
  • 工業的にはオストワルト法によりつくられる。
  • ① アンモニアと空気を混合し、800℃で白金 Pt 網に通じると、アンモニアは酸化されて一酸化窒素になる。
  • ② 一酸化窒素を冷却後、さらに酸素と反応させて二酸化窒素とする。
  • ③ 二酸化窒素を吸収塔で水と反応させ、硝酸と一酸化窒素とする。
  • 式③で生じる NO は酸素と反応するので、最終的にすべて硝酸になる。
  • 硝酸は強酸性で酸化剤として働く。
① 4NH3 + 5O2 →(Pt触媒) 4NO + 6H2O
② 2NO + O2 →(冷却) 2NO2
③ 3NO2 + H2O → 2HNO3 + NO
総：NH3 + 2O2 → HNO3 + H2O
🦴
リン P 磷
  • 15族の非金属元素で、価電子を5個もつ。
  • リンの単体は、リン鉱石を電気炉中でけい砂 SiO2 とコークス C と反応させてつくられる。
  • 黄リン P4：淡黄色ろう状固体、四原子分子、空気中で自然発火、水中保存、猛毒。
  • 赤リン：赤褐色固体、毒性小、マッチの側薬や医薬品・肥料・農薬の原料。
  • 十酸化四リン P4O10 は水と反応してリン酸を生成する。ただし、リン酸 H3PO4 を生成するには加熱が必要。加熱しない場合は別の酸性物質が生じる。
  • リン酸 H3PO4 は中程度の強さの酸性を示す。
  • 生体内では有機化合物と結合して DNA などをつくっている。
  • 骨や歯の主成分はヒドロキシアパタイト Ca5(PO4)3(OH)。
P4O10 + 6H2O →(加熱) 4H3PO4
