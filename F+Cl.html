ハロゲン（17族）のまとめ

彩色 = 考试重点，会出题 灰色 = 了解即可，不出题
🔬
ハロゲン総論 卤素总论
  • 17族の元素をハロゲンという。
  • ハロゲンの原子は価電子を7個もち、1価の陰イオンになりやすい。
  • 陰イオンになりやすい傾向は周期表で上にある元素ほど強い。
  • フッ素は全元素の中で最も陰性が強い。
💠
ハロゲン単体の性質
  • 単体は二原子分子からなり、有色・有毒で、酸化作用が強い。
  • 酸化力の強さは F2 > Cl2 > Br2 > I2 の順。原子番号が小さいほど酸化力が強い。
単体常温での状態
F2淡黄色・気体
Cl2黄緑色・気体
Br2赤褐色・液体
I2黒紫色・固体（昇華性あり）
水素との反応
  • F2：冷暗所でも爆発的に反応
  • Cl2：常温でも光により爆発的に反応
  • Br2：触媒の存在下で加熱により反応
  • I2：触媒の存在下で加熱により反応（可逆で不徹底）
水との反応
  • F2：最も激しく反応し、O2 が発生
  • Cl2：水に少し溶け、一部が反応して HCl と HClO を生じる
  • Br2：Cl2 より反応性は弱いが、同様に反応
  • I2：水に溶けにくく、反応しにくい（エタノール・ヘキサンなど有機溶媒には溶けやすい）
2F2 + 2H2O → 4HF + O2
Cl2 + H2O ⇌ HCl + HClO
⚗️
ハロゲン単体の製法 制法
  • 実験室で Cl2：MnO2 に濃塩酸を加えて加熱
  • 実験室で Cl2（別法）：さらし粉（漂白粉）CaCl(ClO)·H2O に濃塩酸を加える
  • 捕集は下方置換で行う。
  • 除雑：まず水に通して HCl を除き、次に濃硫酸に通して水蒸気を除き、乾燥 Cl2 を下方置換で得る。
  • 工業的製法：塩化ナトリウム NaCl 水溶液の電気分解でつくる。
MnO2 + 4HCl →(加熱) MnCl2 + 2H2O + Cl2
CaCl(ClO)·H2O + 2HCl → CaCl2 + Cl2 + 2H2O
2NaCl + 2H2O → 2NaOH + H2 + Cl2
⚡
ハロゲン単体の反応 氧化作用
  • Cl2 は H2 や Cu と反応して HCl や CuCl2 を生じる。
  • ハロゲン単体には酸化作用がある。
  • フッ素はハロゲン単体中で最も強い酸化力をもつ。
  • ヨウ化物イオンを含む水溶液に塩素水を加えるとヨウ素 I2 が遊離する。
  • ヨウ素デンプン反応：I2 はデンプンに加えると青色を呈する。
  • 塩素は塩基と反応して塩をつくる（NaCl + NaClO）。
  • 次亜塩素酸 HClO：弱酸だが酸化力が強く、漂白剤や殺菌剤に用いられる。
  • 塩素酸 HClO3：強酸。塩類は酸素の製法に使われる。
  • 過塩素酸 HClO4：強酸だが酸化力は弱い。
H2 + Cl2 →(光) 2HCl
2I− + Cl2 → I2 + 2Cl−
2KCl + F2 → 2KF + Cl2
2NaOH + Cl2 → NaCl + NaClO + H2O
💨
ハロゲン化水素 卤化氢
  • 常温常圧では無色の気体で、有毒、強い刺激臭をもつ。
  • 水によく溶け、フッ化水素 HF 以外の水溶液は強い酸性を示す。
塩化水素 HCl
  • 工業的製法：塩素 Cl2 と水素 H2 を直接反応させる。
  • 実験室的製法：NaCl に濃硫酸を加えて穏やかに加熱。下方置換で集める。
  • HCl 水溶液を塩酸という。
  • アンモニアと反応して白煙（NH4Cl）を生じる。
  • 塩酸にマグネシウム Mg 片を入れると、水素 H2 を発生して溶ける。
NaCl + H2SO4 →(加熱) NaHSO4 + HCl
HCl + NH3 → NH4Cl（白煙）
Mg + 2HCl → MgCl2 + H2
フッ化水素 HF
  • 製法：CaF2（蛍石の主成分）に濃硫酸を加えて加熱する。
  • HF 水溶液はフッ化水素酸とよばれる弱酸である。
  • フッ化水素酸はガラスなどのケイ酸塩や石英 SiO2 を溶かすので、ポリエチレン容器で保存する。
  • HF は F の電気陰性度が大きく、分子間で強い水素結合をつくるため、沸点が高くなる（20℃）。
  • H-F の結合距離は短く、H と F は強く結びついているため、HF は弱酸である。
CaF2 + H2SO4 → CaSO4 + 2HF
SiO2 + 6HF → H2SiF6 + 2H2O

ハロゲン化銀 卤化银
  • AgF 以外のハロゲン化銀は水に溶けない。
  • ハロゲン化物イオンを含む水溶液に AgNO3 水溶液を加えると沈殿が生じる。
