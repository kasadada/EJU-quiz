酸素と硫黄（16族）のまとめ

彩色 = 考试重点，会出题 灰色 = 了解即可，不出题
💨
酸素の単体 氧气
  • 16族の非金属元素（O、S）は価電子を6個もつ。
  • 酸素は空気中に体積比で約21％存在し、生物の呼吸に不可欠。
  • 地殻中で最も存在量の多い元素である（約49％）。
  • 工業的には液体空気の分留で得られる。
  • 実験室では水の電気分解や過酸化水素の分解で発生させ、水上置換で集める。
2H2O2 →(MnO2) 2H2O + O2
🌬️
オゾン O3 臭氧
  • オゾン O3 は酸素 O2 と同素体の関係にある。
  • 酸素に紫外線を当てるか、酸素中での無声放電により生じる。
  • 特異臭のある淡青色の気体で、毒性が強い。
  • 分解して酸素になりやすく、強い酸化作用を示す。
  • 湿ったヨウ化カリウムデンプン紙を青紫色に変える。
  • 地上 20〜30 km にオゾン層があり、紫外線の一部を吸収している。
3O2 →(無声放電) 2O3
2KI + O3 + H2O → 2KOH + I2 + O2

オキソ酸 含氧酸
  • 中心となる原子に酸素原子が結合し、さらにその酸素原子のいくつかに水素原子が結合した構造をもつ酸。
  • 酸性は、水素原子と結合していない酸素原子の数が多いほど強くなる傾向がある。
  • HNO3、H2SO4、HClO4 など、酸素原子の数が水素原子の数より2つ以上多いオキソ酸は強酸。

💧
過酸化水素 H2O2
  • 過酸化水素 H2O2 は無色の液体（沸点 151℃）。
  • 濃い水溶液は酸化力が強く有機物を発火させる。
  • 3％水溶液はオキシドールとよばれ、殺菌消毒剤に利用。
  • 漂白剤やロケット燃料にも用いられる。
  • 不安定で分解しやすく、触媒により水と酸素になる。
  • 天然の水分子の 99.73％ は 1H216O。
  • 重水素 D のみを含む水 D2O を重水、通常の水を軽水ともいう。
2H2O2 →(MnO2) 2H2O + O2
🟡
硫黄の単体と同素体
  • 硫黄 S は黄色のもろい固体で、火山地帯で産出。
  • 工業的には石油精製工程の脱硫で得られる。
  • 同素体には斜方硫黄・単斜硫黄・ゴム状硫黄がある。
  • どれも無臭で水に不溶。常温では斜方硫黄が最も安定。
  • 斜方硫黄を120℃に加熱融解後冷却すると単斜硫黄。
  • 250℃に加熱した液体硫黄を冷水に注いで急冷するとゴム状硫黄。
  • 斜方硫黄・単斜硫黄は王冠状の環状分子 S8、ゴム状硫黄は鎖状分子 Sx。
  • 溶解性：斜方硫黄と単斜硫黄は CS2 に溶ける、ゴム状硫黄は溶けない。
🔥
硫黄の反応 ・ 硫化水素 H2S
  • 硫黄は反応性が高く、多くの元素と結合して硫化物をつくる。
  • 空気中で燃焼させると青い炎を出し、SO2 になる。
S + O2 → SO2
硫化水素 H₂S
  • 無色・腐卵臭の有毒な気体。
  • 火山ガスや鉱泉に含まれ、タンパク質の腐敗でも発生。
  • 実験室：硫化鉄(Ⅱ) FeS に希硫酸や塩酸を加えて発生させ、下方置換で捕集。
  • 水溶液は弱酸性。多くの重金属イオンと反応して硫化物の沈殿を生じる。
  • 還元剤としても働き、SO2 や I2 と反応する。
FeS + H2SO4 → FeSO4 + H2S
FeS + 2HCl → FeCl2 + H2S
2H2S + SO2 → 2H2O + 3S
H2S + I2 → 2HI + S
🌫️
二酸化硫黄 SO2
  • 刺激臭のある無色の有毒な気体。
  • 火山ガスや鉱泉に含まれ、黄鉄鉱 FeS2、黄銅鉱 CuFeS2 の燃焼で発生。
  • 実験室：亜硫酸ナトリウム Na2SO3 または亜硫酸水素ナトリウム NaHSO3 に希硫酸を加える、または銅に濃硫酸を加えて加熱。下方置換で捕集。
  • 水溶液は弱酸性：SO2 + H2O ⇌ H+ + HSO3−
  • ヨウ素などの酸化剤に対して還元剤として働く。
  • 漂白作用があり、漂白剤として利用される。硫化水素に対しては酸化剤として働く。
    （漂白性は SO2 の還元性に由来する）
NaHSO3 + H2SO4 → NaHSO4 + H2O + SO2
Cu + 2H2SO4 →(加熱) CuSO4 + 2H2O + SO2
SO2 + I2 + 2H2O → H2SO4 + 2HI
⚗️
硫酸 H2SO4 の製造と性質
  • 工業的製法：接触法。
  • ① 硫黄 S の燃焼で得た SO2 を、V2O5 触媒下で空気中の酸素と反応させ SO3 とする。
  • ② SO3 を97〜98％硫酸に吸収させて発煙硫酸とし、希硫酸と混合して濃硫酸とする。
2SO2 + O2 →(V2O5) 2SO3
SO3 + H2O → H2SO4
濃硫酸の性質
  • 市販の 98％硫酸 を濃硫酸とよぶ。無色・密度大（約 1.8 g/mL）・粘性大の液体。
  • 濃硫酸の性質：不揮発性・吸湿性・脱水作用・酸化作用・溶解熱大。
  • 不揮発性の例：NaCl + H2SO4 → NaHSO4 + HCl
  • 脱水作用の例：C12H22O11 → 12C + 11H2O（ショ糖が炭化）
  • 熱濃硫酸の酸化作用：Cu、Hg、Ag とも反応し SO2 を発生。
希硫酸の性質
  • 希硫酸は強酸性。水素よりイオン化傾向の大きい金属と反応し H2 を発生（Pb は溶けにくい）。
  • 弱酸の塩（亜硫酸塩、酢酸塩など）に加えると弱酸を遊離する。
  • Ba や Pb の硫酸塩は水に溶けにくい。BaSO4 の白色沈殿は SO42− の検出に用いられる。
BaCl2 + H2SO4 → BaSO4↓ + 2HCl
